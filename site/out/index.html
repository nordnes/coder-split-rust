Coder (Rust backend)

This deployment is running the Rust backend rewrite of Coder. The embedded React SPA build output (site/out/) has not been populated in this build, so this placeholder is served from the single-binary rust-embed fallback instead.

The API remains fully functional:

  • /api/v2/buildinfo — running version & metadata
  • /healthz — liveness probe
  • /api/v2 — REST API root

To build with the real SPA, run the Coder frontend build so site/out/index.html is overwritten before compiling coderd.
